# Historical AuroraEdge project material

NorthFlux Security began under the AuroraEdge name and later formed Leon Chapman's Belfast Metropolitan College final-year project. The academic documents in this repository preserve that history and describe the system as it existed at the time.

Historical documents may contain old product names, version numbers, test snapshots, submission instructions, and design limitations that have since changed. They are evidence of the project's development rather than current operator guidance.

Current product guidance starts in the repository [README](../../README.md), [architecture](../ARCHITECTURE.md), [deployment guide](../DEPLOYMENT.md), and [security policy](../../SECURITY.md).

The historical set currently includes the academic notebook, project specification, stage notes, progress records, original status and verification reports, competitor study, release notes, and development timeline. They will be moved into this directory incrementally while links are kept stable.
