# AuroraEdge academic archive

NorthFlux Security began under the AuroraEdge name and later formed Leon Chapman's Belfast Metropolitan College final-year project. This archive preserves the development record; it is not the installation guide for today's product.

The original documents and figures are grouped under `archive/` so they remain available to assessors and reviewers without crowding the current product guides. Product names, research findings, dated test counts, and historical commands remain evidence of the time they were written. Some old commands refer to components that no longer exist. Links to current guidance and moved document paths have been updated.
